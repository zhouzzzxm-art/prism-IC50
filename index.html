使用说明：横轴、模型和 0 浓度

横轴与输入值

这里始终输入原始浓度。若在 Prism 输入的 X 已是 log10(浓度)，应选择 log(inhibitor) vs. response；X 仍是原始浓度时，选择 [Inhibitor] vs. response，再把图轴设为 log。

等差浓度取 log 后通常不等距；等比浓度才等距。

模型选择

平台和中间过渡区覆盖充分时，可拟合完整 4PL。中间浓度少时，比较固定斜率模型需要科学依据。只有可靠对照界定了 0% 与 100%，才考虑固定平台。不要单凭更高的 R² 选模型。

本工具仅支持对称、单相下降；上升、双相与钟形响应需其他模型。

0 浓度处理

log10(0) 没有有限值。这里用下降模型在 0 浓度的极限 Y(0)=Top 纳入拟合。log 图仅绘制正浓度，并在图旁列出 0 浓度观测；线性轴可直接显示它。

不把 0 改成 1 或极小数，也不补造缺失实验点。
公式、计算范围与 Prism 对应设置
Y = Bottom + (Top − Bottom) / [1 + (C / IC50)−HillSlope]

C 为原始浓度；C=0 时使用 Y=Top；IC50>0，HillSlope<0，Top>Bottom。正浓度上等价于 Prism 的下降型可变斜率公式。通过确定性多起点优化拟合 log(IC50) 和斜率幅度；自由平台在每步用线性最小二乘解出。数值搜索范围：IC50 为输入正浓度范围外扩 6 个数量级，|HillSlope| 约 0.001–50；命中边界会提示。

每个输入复孔等权。RMSE = √(SSE/n)，单位为百分点；R² = 1−SSE/SST，仅描述拟合，不验证模型。图线是预测值，散点是输入值。此版本不计算置信区间，不包含加权、离群值自动剔除或全局拟合；关键研究结论应在 Prism 中用匹配设置复核。与 Prism 的优化细节、约束或置信区间设置不同，结果可能存在差异。
